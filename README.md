## 建议先看什么

先看 09 的路线，再配合实践教程与 06 的机制推导。10 连接 AlphaZero、单轮 LLM 和近期多轮 Agent 方法；07、08 用于长程 Agent 深入阅读；01–05 作为背景资料和备课素材。

当前报告安排为 **82 分钟内容与演示 + 8 分钟问答**，具体分配见 09、10；早期 80＋10 的机制/Agent 双重点版保留作备选。演讲顺序不等于历史顺序：REINFORCE（1992）早于 DQN（2015）；DPO 是偏好优化分支，不能放进一条“算法逐代取代”的链条。
