## 1｜一个任务，三种学习信号（00–03）

**画面：** 一个房间，钥匙在左，锁住的门在右，门后是目标；旁边放一个“生成函数并通过测试”的任务框。

**讲述：** “今天从一个很具体的问题开始：一个模型第一次走进房间，我们希望它拿钥匙、开门、到达目标。可以给它大量正确路线，让它模仿；也可以让它自己试，成功时给奖励。后者的问题是，它可能走了二十步才知道成功，这二十步中哪些值得保留？后来我们把房间换成代码仓库，把移动换成读文件、改代码和运行测试，这个问题依然存在。”

交代报告范围：先看行为怎样学习，再把策略换成语言模型。没有实测结果前，不在开场放伪造的“训练前后”动画。

**过渡：** “先不用算法名字，把这个学习问题写清楚。”

## 2｜策略与环境怎样构成闭环（03–06）

**画面：** 观测 → 策略 → 动作 → 环境 → 新观测／奖励。逐个标出状态、观测、动作、策略。

**讲述：** “策略是一个给动作分配概率的函数。它先采取动作，环境再给下一次观测和反馈。与固定数据上的预测不同，我们采取什么动作，会影响以后看到什么数据。门外的完整世界状态与智能体当前看见的画面，也可能不是同一回事。”

现场请听众判断：一张局部截图是否足以决定下一步？借此解释部分可观测，不展开 POMDP 推导。

**依据：** [Sutton & Barto, 2018](https://mitpress.mit.edu/9780262039246/reinforcement-learning/)。

## 3｜即时奖励与累计回报（06–09）

**画面：** 两条路线：直接走到锁门前失败；先远离门拿钥匙再成功。列出奖励序列。

**板书：** \(G_t=\sum_{k=t}^{T-1}\gamma^{k-t}r_k\)，\(J=\mathbb E[G_0]\)。说明本报告 \(r_t\) 是执行 \(a_t\) 后的奖励。

**讲述：** “这一步没得分，不代表这一步没有价值。先拿钥匙的路线看起来绕远，但它改变了最终成功的可能性。RL 的目标是期望累计回报，所以我们既要探索未知路线，也要把最终结果分配回前面的决策。”

给一个反例：奖励每开一次门就加分，模型可能反复开关门。奖励设计与真实目标一致，是实验的一部分。

## 4｜V、Q、A 分别在问什么（09–12）

**画面：** 同一位置旁边标注三个问题：处境如何；做某动作后如何；相对平均好多少。

**板书：** \(V^\pi(s)\)、\(Q^\pi(s,a)\)、\(A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)\)。

**讲述：** “V 是当前处境的平均前景，Q 把当前动作也固定下来，A 再减掉这个状态下的平均表现。它们都在评价未来，不是对画面或文本做一个泛泛的质量打分。”

标注两条路线：先学 Q 再选择动作；直接学习动作概率。后面按教学需要先讲 DQN，提醒 REINFORCE 的历史更早。

## 5｜Bellman：把下一步的估计变成当前目标（12–15）

**画面：** 三个连续格子，奖励从终点通过价值估计向前传播。

**板书：** \(y=r+\gamma\max_{a'}Q(s',a')\)。举例：当前奖励 0，下一步最大 Q 为 0.8，\(\gamma=0.9\)，则目标为 0.72；真正终止时不继续 bootstrap。

**讲述：** “这里没有给当前动作人工写一个标签，而是用一步奖励加上下一步价值形成目标。这叫自举。它很高效，但标签也由模型参与估计，所以误差可能互相影响。”

**依据：** [Watkins & Dayan, 1992](https://doi.org/10.1007/BF00992698)。

## 6｜DQN 的两个稳定装置（15–18）

**画面：** 在线网络、回放池、目标网络；用不同线型表示梯度路径和数据路径。

**讲述：** “当状态是图像，就用神经网络近似 Q。连续游戏帧太相似，经验回放让训练从过去经验中随机抽样。目标网络慢一点更新，让在线网络追逐的目标不至于每一步都迅速变化。”

明确目标网络端不求梯度。展示一条经验从收集到回放、目标计算再到更新的路径即可，不展开完整 Atari 卷积网络结构。

**依据：** [Mnih et al., Nature 2015](https://www.nature.com/articles/nature14236)。

## 7｜从价值路线转向策略路线（18–20）

**画面：** 左侧 Q(s,a) → argmax／探索；右侧 \(\pi(a\mid s)\) → 采样。

**讲述：** “价值方法让我们先学评价，再据此行动。但语言模型已经是一个动作概率模型：它直接告诉我们下一个 token 的分布。能不能省去显式的动作价值搜索，直接根据结果调整这个分布？这就是下一条路线。”

避免表述为 DQN 无法处理语言；强调方法选择与已有策略表示的自然衔接。

## 8｜REINFORCE：让高回报行为更常发生（20–23）

**画面：** 二选一策略，动作 A 概率 0.4，采样后取得正回报。概率柱向上移动，注明“教学示意”。

**板书：** \(\hat g=\sum_tG_t\nabla\log\pi_\theta(a_t\mid s_t)\)。此后策略梯度例子采用有限回合 \(\gamma=1\)。

**讲述：** “不是对离散动作本身求导，而是对采样动作的对数概率求导。回报告诉我们这次尝试应该被强化多少。关键的等式是概率的导数可以改写成概率乘以对数概率的导数。”

推导只写 \(\nabla p=p\nabla\log p\)。完整折扣约定放备份页。

**依据：** [Williams, 1992](https://link.springer.com/article/10.1007/BF00992696)。

## 9｜baseline：成功也要看题目难度（23–26）

**画面：** 简单题和困难题都得 0.6 分；两题预期分别为 0.9、0.2。

**讲述：** “0.6 分究竟好不好，要看本来预期是多少。减去一个状态相关的 baseline，让更新更关心超出预期的部分。只要 baseline 不依赖当前采样动作，适当条件下它在期望梯度中抵消，却有机会减小噪声。”

**板书：** \((G_t-b(s_t))\nabla\log\pi\)；\(b(s)\nabla\sum_a\pi(a\mid s)=0\)。强调 Actor 更新中不沿 advantage 反传到 baseline。

## 10｜Actor–Critic：边行动，边预测后续收益（26–29）

**画面：** Actor 给动作，Critic 给 V；环境结果回来后更新两者。

**讲述：** “每次等到整局结束才知道回报，噪声会很大。Critic 先预测从这里继续的收益，用短期反馈修正预测，再辅助 Actor 更新。它不是告诉 Actor 哪句话好听，而是在预测当前策略继续执行的结果。”

写 \(\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)\)，口头补终止 mask。说明 Actor–Critic 是方法家族，A3C 是代表性实现。

**依据：** [Mnih et al., 2016](https://arxiv.org/abs/1602.01783)。

## 11｜GAE：短期预测与长程结果之间的折中（29–32）

**画面：** 当前 TD 误差、下一步 TD 误差、再下一步，用逐渐变浅的权重连接。

**板书：** \(\hat A_t=\delta_t+\gamma\lambda\delta_{t+1}+(\gamma\lambda)^2\delta_{t+2}+\cdots\)。

**讲述：** “我们可以依赖短期预测，也可以等更长的结果。GAE 把不同跨度的信息加权组合，控制估计噪声与对价值预测的依赖。Critic 不准时，参数选择的影响尤其明显。”

**过渡：** “现在即使知道该鼓励哪个动作，还有一个问题：一次应该鼓励多少？”

**依据：** [Schulman et al., GAE](https://arxiv.org/abs/1506.02438)。

## 12｜更新过大，旧经验可能不再可靠（32–35）

**画面：** 同一批轨迹被新旧策略解释；展示一个动作从概率 0.1 变成 0.8。

**讲述：** “我们拿到的轨迹来自旧策略。如果更新后行为分布完全变了，还一直拿原来的优势反复优化，就可能偏离数据能支撑的范围。TRPO 引入信赖域思路，PPO 用更方便实现的近端更新目标。”

定义 \(\rho=\pi_\theta/\pi_{\rm old}\)。old 是该批数据的行为策略，更新这一批时分母冻结。

**依据：** [TRPO](https://proceedings.mlr.press/v37/schulman15.html)、[PPO](https://arxiv.org/abs/1707.06347)。

## 13｜PPO-Clip：用两次算术理解公式（35–39）

**画面：** 横轴概率比、纵轴目标，正优势和负优势两张简图。没有真实数据，用“解析目标函数”标注。

展示完整 PPO-Clip 公式，然后按 \(\epsilon=0.2\) 算两次：

| A | 概率比 | 未裁剪项 | 裁剪项 | min |
|---:|---:|---:|---:|---:|
| 2 | 1.5 | 3 | 2.4 | 2.4 |
| -2 | 0.5 | -1 | -1.6 | -1.6 |

**讲述：** “好动作的概率已经提高很多时，不再继续给额外激励；坏动作的概率已经降很多时，也限制继续下降的激励。它裁剪的是目标里的收益，不是硬性保证整个模型的所有概率都在这个区间。”

让听众判断 \(A>0,\rho<1\) 时是否也应该停梯度，借此检验对 min 的理解。

## 14｜PPO 训练循环与三个角色（39–42）

**画面：** rollout → 奖励与价值 → GAE → 几轮 minibatch 更新 → 重新采样。

**讲述：** “PPO 可以把昂贵的新轨迹复用几次，但不意味着随便训练旧数据。我们同时看任务回报、KL、熵和 clip 比例，避免只看一个 loss。”

此处有当前策略、行为策略快照、价值估计。后面进入 RLHF 还会增加 reference 和奖励模型，先为概念区分留位置。

## 15｜把动作换成 token（42–45）

**画面：** 提示、前缀、下一个 token，底部放序列概率的乘积与 log-prob 的求和。

**讲述：** “语言模型本来就是策略。生成的每个 token 是一个随机动作，最终答案对不对可以在末尾判断。整段回答可以看作一次任务层面的动作，也可以拆成 token 决策。只有当模型调用工具并接收新观察时，我们才进入外部多步交互的情形。”

用短程序的生成与测试举例，不把更长的思维链直接称为更长的外部任务。

## 16｜RLHF：四个角色，不是四个同义词（45–49）

**画面：** SFT → 收集偏好 → 奖励模型 → PPO；旁边一张 Actor、Reference、Reward、Critic 对照表。

**讲述：** “偏好模型把人类比较转换成可批量计算的奖励，Critic 估计从某个前缀继续生成的期望回报，Reference 提供行为参照，Actor 才是我们要改进的生成模型。它们在工程上可能共享组件，但职责要分清。”

解释 KL 正则：不仅追求奖励，还控制相对参考策略的偏离。old policy 随数据批次变化，reference 通常在一个训练阶段里冻结。

**依据：** [InstructGPT, 2022](https://arxiv.org/abs/2203.02155)。

## 17｜DPO：从奖励到策略的关系反过来用（49–52）

**画面：** 同题 chosen/rejected 两个回答；三行式子：KL 目标的最优策略 → 奖励的 log-ratio 表达 → 偏好差里常数相消。

**讲述：** “如果目标是带参考策略约束的奖励最大化，最优策略与奖励有指数形式的联系。把这个联系代入偏好概率模型，可以直接优化策略的偏好差，不必先训练一个单独的显式奖励模型。”

只展示 DPO 核心 log-ratio 差；配分函数为什么消掉讲清即可。不展开完整变分证明。

**依据：** [Rafailov et al., DPO](https://arxiv.org/abs/2305.18290)。

## 18｜DPO 与 PPO 如何选择（52–55）

**画面：** 数据来源、是否在线采样、是否显式奖励模型、典型目标四行比较。

**讲述：** “已有可靠偏好对时，标准 DPO 的流程通常更直接。如果目标需要模型在新任务上持续尝试、执行并获得验证反馈，在线 RL 更自然。两者不是一条线上的新旧版本，实际也可以先做偏好优化，再做特定任务 RL。”

抛出下一个问题：如果有精确答案或可运行测试，还需要人类逐条比较吗？

## 19｜GRPO：同一道题多做几次（55–58）

**画面：** 一个问题分出四个回答，奖励分别为 1、0、0、1。

**讲述：** “有些时候，我们不另训练一个 Critic，而是让同一个模型对同一题尝试几次，用这组结果做相对评价。做得比组平均好的输出，得到正优势。这是 GRPO 最容易理解的入口。”

指出 GRPO 来自 DeepSeekMath；奖励可以来自验证器，也可以来自奖励模型。不要把 GRPO 定义成“只用正确答案打分”。

**依据：** [DeepSeekMath, §4](https://arxiv.org/html/2402.03300v3)。

## 20｜手算一组优势，再看训练何时没有信号（58–62）

**画面：** \([1,0,0,1]\to\bar R=0.5\to\hat A=[1,-1,-1,1]\)，注明使用总体标准差。

**讲述：** “结果奖励版本把这个相对优势用于整段回答的生成 token，再结合类似 PPO 的概率比目标。它没有指出某个中间思考步骤一定正确，只是提高成功轨迹的相对概率。”

再展示全零组和全一组，请听众判断。解释：中心化结果优势为零；其他正则项仍可能更新。任务过难、过易或采样多样性不足，都可能使训练缺少有效比较。

最后说明省掉 Critic 的收益与多次 rollout 的成本并存。

## 21｜从 R1 到后续训练配方（62–65）

**画面：** R1-Zero、R1、蒸馏三个标签；下方 DAPO、Dr. GRPO、GSPO 各对应一个问题。

**讲述：** “R1-Zero 是从已经预训练的基座开始做 RL；R1 引入冷启动和更多训练阶段。后续工作告诉我们，长度归一化、组内奖励缩放、裁剪和有效样本率都会影响结果。看起来相同的 GRPO 训练器，实际可能对应不同目标。”

保留一项可供追问的事实：TRL 当前文档中的默认 loss 类型与原始 GRPO 不必一致，因此实验必须保存显式配置和版本。

**依据：** [R1](https://arxiv.org/abs/2501.12948)、[DAPO](https://arxiv.org/abs/2503.14476)、[Dr. GRPO](https://arxiv.org/abs/2503.20783)、[GSPO](https://arxiv.org/abs/2507.18071)、[TRL](https://huggingface.co/docs/trl/grpo_trainer)。

## 22｜代码 RL：把测试变成奖励（65–69）

**画面：** 题目 → 候选程序 → 隔离测试 → 奖励 → 更新。下方区分函数题与仓库修复。

**讲述：** “单轮代码题最直接的信号是测试能否通过。训练时可以用全通过，也可以用测试通过比例；评估时要知道分母是整道题还是一个测试用例。更重要的是，训练测试与最终隐藏测试必须分开。”

介绍 SWE-RL 与 DeepSWE 的区别：前者从软件演化数据构造奖励，后者展示多轮代理训练。无需背成绩榜；若使用数字，必须标注模型、基准、候选数和工具框架。

**依据：** [HumanEval](https://arxiv.org/abs/2107.03374)、[SWE-RL](https://arxiv.org/abs/2502.18449)、[DeepSWE](https://www.together.ai/blog/deepswe)。

## 23｜从输出答案，到执行一个任务（69–73）

**画面：** Issue → 搜索 → 读文件 → 修改 → 测试失败 → 再修改 → 提交。用两种背景区分策略生成和环境返回。

**讲述：** “环境返回的报错不是模型自己生成的动作。训练时它参与后续条件信息，但通常不作为策略 action token 计入损失。整条轨迹末尾成功，前面每一步却可能功过不同；这让信用分配和样本成本都更困难。”

讲一个失败案例：模型反复运行同一个测试、没有修改，却不断耗尽预算。可能需要更好的任务分布、价值估计或反馈，而不只是让输出更长。

**依据：** [ReAct](https://arxiv.org/abs/2210.03629)、[RAGEN](https://arxiv.org/abs/2504.20073)。ReAct 用于解释交互格式，不作为 RL 训练证据。

## 24｜长程智能体训练：把环境纳入设计（73–77）

**画面：** 回到钥匙房间；标出初态、观测、动作、奖励、重置和测试布局。

**讲述：** “在代码和工具任务中，环境可以告诉我们目标是否完成，也可以提供部分步骤反馈。反馈太少，模型探索不到成功；反馈定义不当，模型就会学会刷分。先用可控的小任务把训练与评估做通，再增加工具数量、任务跨度和环境复杂度，更容易知道性能变化来自哪里。”

## 27｜问答（82–90）

优先接与听众研究相关的问题。下面是可直接使用的简短回答。

| 问题 | 回答 |
|---|---|
| DQN 和 REINFORCE 是前后升级关系吗？ | 不是。它们代表价值与策略两种路线；REINFORCE 的历史更早。 |
| PPO 会保证策略每一步都改善吗？ | 不作无条件保证。clip 只改变局部目标，仍需监测真实评估结果。 |
| 奖励模型能代替 Critic 吗？ | 职责不同：前者评价输出，后者预测当前状态的后续收益。可能共享组件，但不能直接混称。 |
| DPO 算不算 RL？ | 它从 RLHF 的正则奖励目标推导，但标准训练是偏好对上的直接优化，通常没有在线 rollout 循环。说明采用的定义比简单归类更有用。 |
| GRPO 不需要奖励模型吗？ | 不需要独立 Critic 的原始设计，仍需要奖励来源；该来源可以是规则，也可以是模型。 |
| 全组都错了会怎样？ | 结果中心化优势为零，无法从这组结果比较中知道哪条更好；辅助项可能仍更新。需要检查任务难度和探索。 |
| 只保留正确样本再 SFT 不就行了？ | 这是重要基线。其样本权重和负样本处理与策略梯度不同，必须在相同数据与预算条件下比较。 |
| 为什么不从一个最强模型开始？ | 若任务几乎全对，提升空间和组内信号都很小；应以基线成功率与任务难度共同选型。 |
| RL 是否只是让模型把已有答案更常采出来？ | 一些设置支持这个解释，但不能据此推成普遍不可能性。有限 pass@k 是经验测量，不是完整能力边界。 |
| 长思维链就是长程任务吗？ | 不是。外部多步任务强调行动改变环境、得到新观察并继续决策。 |
| 实验室的 AI 项目应该直接用 GRPO 吗？ | 先明确目标能力、起始模型和可靠反馈。能对同题多个尝试评分时可考虑 GRPO；多轮工具任务还要处理轨迹、信用分配和执行成本。 |
