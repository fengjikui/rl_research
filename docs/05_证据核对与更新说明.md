## 范围与证据层级

本页是首轮通览资料的证据说明。2026-09-12 新增的 [梯度机制专题](06_为什么奖励能通过梯度改进行为.md) 与 [长程 Agent 专题](07_长程Agent强化学习怎样实际训练.md) 各自保留参考文献；后者 §12 另列本轮阅读深度。已运行的是解析玩具例子的数值核验，尚无 LLM／Agent 训练结果。

资料核对截止 2026-09-11。主要依据原论文、作者团队的官方技术报告、官方软件文档与模型卡。没有使用搜索结果里的二手解说作为关键算法结论的唯一依据，也没有把项目自述自动视为独立复现。

本资料集是围绕报告需求的代表性调研，并非带完整纳排标准的系统综述。算法公式是教学性重述，实践资源、任务优先级和两周安排是设计建议。原调研阶段的资源估计并非实测；后续已有 [CPU 教程实验](../tutorials/RESULTS.md) 与 [真实预训练 Qwen 的 GRPO 实战](../grpo_lab/README.md)，请分别查阅其配置、结果与边界。

## 关键事实核对表

| 容易误讲的说法 | 文档采用的表述 | 核对来源 |
|---|---|---|
| REINFORCE 是 DQN 之后出现的 | 教学顺序先 DQN，历史上 REINFORCE 更早 | [Williams 1992](https://link.springer.com/article/10.1007/BF00992696)、[DQN 2015](https://www.nature.com/articles/nature14236) |
| A3C 首次提出 Actor–Critic | A3C 是该家族的代表性深度 RL 实现 | [A3C](https://arxiv.org/abs/1602.01783)、[教材](https://mitpress.mit.edu/9780262039246/reinforcement-learning/) |
| DQN 每个 Atari 游戏都超过人类 | 原文评估 49 款游戏，不能逐项作此断言 | [DQN 原论文](https://www.nature.com/articles/nature14236) |
| PPO clip 保证概率比留在范围内 | clip 作用于目标的激励，不能直接当硬约束 | [PPO](https://arxiv.org/abs/1707.06347) |
| DPO 是比 PPO 更新的在线 RL 算法 | 从相关奖励目标推导；标准形式直接优化偏好对 | [DPO](https://arxiv.org/abs/2305.18290) |
| GRPO 由 R1 首次提出 | DeepSeekMath 已提出 GRPO | [DeepSeekMath §4](https://arxiv.org/html/2402.03300v3) |
| GRPO 不使用任何奖励模型 | 原设计省去独立 Critic；奖励来源可以是模型 | [DeepSeekMath §4.1.2–4.1.4](https://arxiv.org/html/2402.03300v3) |
| 全对／全错组没有任何梯度 | 结果中心化优势为零；KL、熵等其他项仍可能更新 | [原始 GRPO 目标](https://arxiv.org/html/2402.03300v3)；对目标的直接分析 |
| R1-Zero 从零学会语言与推理 | 从已预训练基座开展 RL，省去该阶段的前置 SFT | [R1](https://arxiv.org/abs/2501.12948) |
| 长度上升就是推理变强 | 还可能涉及长度聚合与权重偏差，须看外部正确率 | [Dr. GRPO §3](https://arxiv.org/html/2503.20783v2) |
| SWE-RL 用多轮单元测试反馈训练 | 其代表方法使用软件演化数据和规则相似度奖励 | [SWE-RL 方法](https://arxiv.org/html/2502.18449v1) |
| DeepSWE 59% 是单次采样结果 | 官方同时区分 42.2% pass@1、71.0% pass@16、59% 测试时扩展结果 | [DeepSWE 官方报告](https://www.together.ai/blog/deepswe) |
| DeepSWE 可直接作为单卡两周配方 | 官方案例为 32B、64 H100、6 天；本方案另选小任务 | [DeepSWE 训练设置](https://www.together.ai/blog/deepswe) |
| 使用 ReAct 就已经训练了 RL | ReAct 描述交织推理与行动的框架，权重是否更新需另证 | [ReAct](https://arxiv.org/abs/2210.03629) |
| TinyZero 旧命令是当前推荐安装方式 | 仓库已提示停止积极维护并指向 verl | [TinyZero README](https://github.com/Jiayi-Pan/TinyZero) |
| GRPOTrainer 默认就是原始 GRPO | 检索时文档默认 loss_type 为 dapo，需显式固定配置 | [TRL 配置文档](https://huggingface.co/docs/trl/grpo_trainer) |

## 阅读深度与尚未核实的部分

DeepSeekMath、DAPO、Dr. GRPO、SWE-RL、RAGEN 使用了原论文 HTML，重点核对方法和相关段落；DeepSWE 使用作者团队官方长文核对训练与评价。经典论文结合出版页、论文页及已获取的原文方法信息核对。教材出版页用于确认书目信息与章节阅读入口，没有声称逐页重新核对全书。

2026 年三项工作只核对原始论文页面、摘要、作者与日期。本资料没有完成其全文复核或实验复现，因此不引用它们的精确提升数字，也不将它们列为实践必须依赖的实现。

| 新工作 | 已确认 | 尚需进一步核实 |
|---|---|---|
| [Curriculum RL, 2026-06-21](https://arxiv.org/abs/2606.22317) | 方法包含边界定位、教师指导与 RL | 各阶段额外数据／算力、同预算对照、泛化和复现 |
| [Agentic RL Systems, 2026-07-01](https://arxiv.org/abs/2607.01120) | 轨迹协议、数据反馈与在线系统的主张 | 系统实例的完整实验、可部署性与维护状态 |
| [Environments as Scaffold, 2026-09-08](https://arxiv.org/abs/2609.08404) | 作者提出反馈丰富的环境并报告 SciWorld／BFCL 实验 | 训练／评测反馈是否完全分离、移除提示后的收益、独立复现 |

关于“RL 是否产生新能力”，文档同时保留 [2025 年批判研究](https://arxiv.org/abs/2504.13837) 与 [2026 年课程研究](https://arxiv.org/abs/2606.22317) 的适用边界。后者含教师指导，不把两者当作同条件实验的一正一反。有限 pass@k 只是一种经验测量。

## 软件和模型的复现边界

TRL、verl 和模型卡链接是当前官方入口，不代表已安装成功的锁定环境。文档没有提供未经验证却标为“一键可复现”的训练脚本。开始实验时应保存：Python／PyTorch／CUDA 版本、框架 commit、模型 revision、chat template、显式训练参数、数据哈希与验证器 revision。

0.6B、1.5B、3B 等尺寸与显存分档是原方案选择范围，当时未实测。后续在本机 CPU 上训练的是 0.5B Qwen，不能由其资源记录推断其他尺寸的 GPU 显存。LoRA 能降低部分训练状态成本，但不消除 rollout、激活、KV cache 与可能的参考模型开销。最终资源预算应以对应设备实测为准。
