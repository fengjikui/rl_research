# 为什么奖励能通过梯度改进行为

## 1. 先区分两个“向前面的步骤传播”

强化学习里最容易混淆的是两件事：**时间上的信用分配**，决定后来的结果应该怎样影响先前动作；**神经网络里的反向传播**，计算某个可微损失对参数的导数。前者构造学习信号，后者执行链式求导。二者不是同一个过程。

以代码智能体为例：它先读文件、修改代码、运行测试，二十分钟后发现补丁通过验收。我们通常不对这二十分钟的 shell、文件系统和测试程序求导。我们保留当时的输入和采样动作，重新计算这些动作在语言模型下的 log-prob，再用回报或优势加权这个可微量。

因此，本报告最关键的一句话是：**不必知道“怎样连续地改变答案就能多得一分”；只要能计算“怎样改变参数会让某个答案更可能出现”，再用它的结果评价这个方向。** 以下推导是有限回合、无折扣、环境参数不随策略参数改变的教学设置；出处见参考文献。[^1][^2]

## 2. 从能手算的最小模型开始

模型只有两个动作：A 得 1 分，B 得 0 分。用一个实数参数 z 表示策略：

\[
p=\pi_z(A)=\sigma(z),\qquad \pi_z(B)=1-p.
\]

期望得分为

\[
J(z)=p\times1+(1-p)\times0=p,
\qquad \frac{dJ}{dz}=p(1-p)>0.
\]

梯度上升 \(z\leftarrow z+\eta p(1-p)\) 会提高 z，从而提高选 A 的概率。这里没有神秘之处：我们已经写出了参数如何影响平均得分。

真实任务的问题是，不知道每个候选动作最终会得到几分，也无法枚举所有文本。需要把这个导数改写成**只依赖采样结果**的估计。

### 2.1 同一个导数，可以由尝试估计

如果本次采到 A，\(\frac{d\log\pi(A)}{dz}=1-p\)；如果采到 B，\(\frac{d\log\pi(B)}{dz}=-p\)。让梯度估计等于奖励乘以这个导数：

| 采样动作 | 发生概率 | 奖励 | 本次梯度估计 |
|---|---:|---:|---:|
| A | p | 1 | 1-p |
| B | 1-p | 0 | 0 |

平均梯度为 \(p(1-p)+(1-p)\times0=p(1-p)\)，恰好等于真正的期望得分梯度。单次样本不需要知道另一动作的分数；重复采样在统计上提供了导数。

## 3. 策略梯度究竟证明了什么

对一个给定输入 x，记动作 a 的期望结果为 \(r(x,a)\)，先考虑它与 θ 无直接依赖：

\[
J(\theta)=\sum_a\pi_\theta(a\mid x)r(x,a).
\]

利用 \(\nabla\pi=\pi\nabla\log\pi\)：

\[
\nabla J
=\sum_a r(x,a)\nabla\pi_\theta(a\mid x)
=\sum_a\pi_\theta(a\mid x)r(x,a)\nabla\log\pi_\theta(a\mid x)
=\mathbb E_{a\sim\pi_\theta}[r(x,a)\nabla\log\pi_\theta(a\mid x)].
\]

这个等式把“所有可能动作的求和”变成“从策略采样就能估计的期望”。实际奖励即使随机，只要条件期望对应 r，仍可用采到的奖励估计。适当正则性、可交换求导与求和／积分等条件默认成立。[^2]

**奖励可以不可微。** 二值答案验证、比赛输赢、程序是否通过测试，都可以作为系数。可微的是策略对已经选中动作的概率，不是离散动作或外部结果。

**策略梯度与反向传播的分工：** 策略梯度恒等式决定要估计哪个向量；自动微分沿模型内部计算这个向量；优化器据此更新参数。仅说“高分反向传播回去”漏掉了关键的数学连接。

## 4. 为什么对 log-prob 求导会改变动作倾向

设网络输出 logits \(z_j\)，策略为 softmax：

\[
\pi_j=\frac{e^{z_j}}{\sum_k e^{z_k}},\qquad
\frac{\partial\log\pi(a)}{\partial z_j}=\mathbf1[j=a]-\pi_j.
\]

定义一个单样本 Actor 损失，A 为停止梯度的优势系数：

\[
L=-A\log\pi_\theta(a\mid s),\qquad
\frac{\partial L}{\partial z_j}=A(\pi_j-\mathbf1[j=a]).
\]

梯度下降在 logits 层面产生：

\[
\Delta z_j=\eta A(\mathbf1[j=a]-\pi_j).
\]

当 \(A>0\)，被采样动作的 logit 向上，其他 logit 向下；当 \(A<0\)，方向反转。再由链式法则把 logits 的导数传到网络参数：

\[
\nabla_\theta L=\sum_j\frac{\partial L}{\partial z_j}\nabla_\theta z_j.
\]

这就是为什么可以把它理解成“带正负权重的交叉熵”。和普通 SFT 不同，目标动作来自当前策略尝试，系数来自行为结果，而且可能为负。

这里的 logits 直接更新只是最清楚的解释模型。真实网络共享参数，各位置与样本的梯度会相互作用；不能据此保证每次有限参数更新都让所有正优势样本的概率同时增加。

### 4.1 三动作数值核验

设三个动作的概率是 \([0.2,0.3,0.5]\)，奖励是 \([1,0.2,0]\)，则期望得分 J=0.26。对 logits 的精确期望梯度为

\[
\frac{\partial J}{\partial z_j}=\pi_j(r_j-J),\qquad
\nabla_z J=[0.148,-0.018,-0.130].
\]

以步长 0.5 更新三个独立 logits，可得：

| 量 | 更新前 | 精确期望梯度更新后 |
|---|---:|---:|
| A 的概率 | 0.200000 | 0.219486 |
| B 的概率 | 0.300000 | 0.303006 |
| C 的概率 | 0.500000 | 0.477507 |
| 期望得分 | 0.260000 | 0.280087 |

注意 B 的 logit 梯度为负，但概率略升，因为 softmax 同时归一化所有 logits。应该关注总体目标的方向，不能说所有低于平均分的动作概率在联合更新中必然下降。

上述数字由 [标准库核验脚本](../examples/policy_gradient_check.py) 计算。脚本同时用有限差分核对导数；这是一项解析玩具实验，不是语言模型能力提升结果。

## 5. “越来越倾向高分”是期望和局部意义，不是每步保证

对精确梯度，小步长下泰勒展开给出

\[
J(\theta+\eta\nabla J)
=J(\theta)+\eta\|\nabla J\|^2+O(\eta^2).
\]

只要不在驻点且步长足够小，一阶变化为正。若使用无偏估计 \(\hat g\)，固定 θ 时

\[
\mathbb E[J(\theta+\eta\hat g)-J(\theta)]
=\eta\|\nabla J\|^2+O(\eta^2\mathbb E\|\hat g\|^2),
\]

在适当平滑性和矩条件下，一阶方向仍正确，但有限步长、方差和曲率都会影响真实结果。以上直接适用于梯度更新的教学分析，不能原样当成 Adam、clip 等所有实现的单调性定理。

同一个三动作例子，如果只采到 B，并以 V=0.26 为 baseline，该样本的梯度是 `[0.012,-0.042,0.030]`；一步更新后期望回报反而变成约 0.259302。**无偏估计可以抽到让真实目标下降的一次样本。** 脚本对此有明确校验。

还必须区分奖励与真实目标：若测试有漏洞，梯度可能很有效地提高测试分数，同时降低真正的软件质量。优化有效与目标正确是两项不同要求。

## 6. 从一次动作到整条轨迹：不穿过环境求导

令轨迹 \(\tau=(s_0,a_0,\ldots,s_T)\)，其概率分解为

\[
p_\theta(\tau)=\rho_0(s_0)\prod_{t=0}^{T-1}
\pi_\theta(a_t\mid s_t)P(s_{t+1}\mid s_t,a_t).
\]

环境动力学 P 不由 θ 参数化，因此

\[
\nabla_\theta\log p_\theta(\tau)
=\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t).
\]

所以

\[
\nabla J=\mathbb E_{\tau\sim\pi_\theta}
\left[R(\tau)\sum_t\nabla\log\pi_\theta(a_t\mid s_t)\right].
\]

关键不是环境对动作不敏感；环境当然会受动作影响。关键是这条路径的概率中，θ 的直接可微依赖由策略项承载。环境的影响已经进入采样分布和最终回报。

如果环境本身包含另一个也由同一 θ 控制的可训练决策模块，就必须把那部分策略概率一并纳入目标，不能直接把它当作固定 P。

### 6.1 最后的奖励，为什么能影响早期行动

完整轨迹的 log-prob 是各行动 log-prob 的和，因此终局回报可以同时给早期行动的梯度加权。跨很多轨迹，那些经常出现在高回报轨迹中的决策方向，平均上得到更大支持。

但一条成功轨迹可能包含无用动作，甚至包含后来被修正的错误。均匀终局奖励不提供逐步因果证明，只提供有效但可能高方差的统计信号。长程信用分配研究就在改进这种粗糙信号。

利用因果性，还可以去掉动作发生之前的奖励，改用 reward-to-go：

\[
\nabla J=\mathbb E\sum_tG_t\nabla\log\pi_\theta(a_t\mid s_t),
\quad G_t=\sum_{k=t}^{T-1}r_k.
\]

本文这一部分固定 \(\gamma=1\)。若目标是折扣初始状态回报，轨迹公式中还需相应外侧 \(\gamma^t\)，或一致地改用折扣访问分布。

## 7. baseline 与 Actor–Critic：改善信号估计

只用绝对分数会混入任务难度与环境随机性。可以减去状态相关、对当前采样动作独立的 baseline：

\[
\hat g=\sum_t(G_t-b(s_t))\nabla\log\pi_\theta(a_t\mid s_t).
\]

因为 \(\mathbb E_a[b(s)\nabla\log\pi(a\mid s)]=b(s)\nabla\sum_a\pi(a\mid s)=0\)，它不会改变期望梯度。合适的 baseline 可以降方差，但任意 baseline 不保证降方差；状态价值也不是所有参数化下唯一最优的方差 baseline。[^1]

**Critic 的任务**是估计 \(V^\pi(s)=\mathbb E[G_t\mid s]\)。它在 Actor 损失里提供参照，或者通过 bootstrap 形成优势估计。一个典型一步估计是

\[
\delta_t=r_t+\gamma(1-d_t)V_\phi(s_{t+1})-V_\phi(s_t).
\]

这里需要分清两种情况：用真实 Monte Carlo 回报减去动作独立 baseline，本身可保持无偏；用不准确的 Critic bootstrap 代替未来回报，则会引入估计偏差。Actor–Critic 在样本效率、方差与估计误差之间权衡。A3C 是代表工作，GAE 把多步 TD 误差组合起来。[^3][^4]

\[
\hat A_t^{\rm GAE}=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}.
\]

讲述顺序应是：REINFORCE 已经给出正确方向，但信号太吵；baseline 提供比较；Critic 学比较基准并支持 bootstrap；GAE 选择使用多长的未来信息。

## 8. 真实训练里哪条路径有梯度

下面是 PyTorch 风格伪代码，展示 on-policy REINFORCE／Monte Carlo baseline 的一个更新，不是完整可运行的 PPO 训练器：

```python
with no_grad():
    episodes = collect_rollouts(policy, environment)
    returns = reward_to_go(episodes)

logp = policy.log_prob_of_saved_actions(episodes)  # 重新前向，有梯度
values = critic.value_of_saved_states(episodes)  # 有梯度
adv = (returns - values).detach()                # Actor 不沿优势反传
actor_loss = -(adv * logp * action_mask).sum() / num_episodes
critic_loss = ((values - returns.detach()) ** 2 * value_mask).sum() / num_states

optimizer.zero_grad()
(actor_loss + value_weight * critic_loss).backward()
optimizer.step()
```

Reward、动作 ID、保存的环境返回是数据。log-prob 必须来自当前网络的可微前向，不能把采样时已 detach 的 log-prob 直接拿来当唯一训练图。上例按回合平均、动作求和以对应推导；如果改成每条轨迹按 token 数平均，会改变不同长度样本的相对权重。

工具输出在策略动作损失里被 mask，不代表这些输入完全不能影响参数梯度：它们仍作为上下文参与计算后续动作概率。只是不能把环境产生的 token 当成 Actor 选择过的 action 来求策略梯度。

## 9. PPO：同一个方向，加上数据复用与更新约束

采样策略固定为 \(\pi_{\rm old}\)，当前模型是 \(\pi_\theta\)，定义

\[
\rho_t=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\rm old}(a_t\mid s_t)}.
\]

在未裁剪部分，\(\nabla(\rho_t\hat A_t)=\rho_t\hat A_t\nabla\log\pi_\theta(a_t\mid s_t)\)。在开始更新时 \(\rho_t=1\)，方向就回到优势加权的策略梯度。PPO-Clip 使用

\[
L^{\rm clip}=\mathbb E_t\min\big(\rho_t\hat A_t,
\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t\big).
\]

它限制的是沿“有利方向”移动过远后的额外激励：正优势且概率比过高，或负优势且概率比过低时，单项会进入平坦区。朝坏方向移动的样本仍需要纠正，不能把两侧都简单说成“超过区间就零梯度”。[^5]

概率比修正了旧状态下动作分布的变化，并未把所有新状态访问分布变化都精确纠正；这是局部 surrogate。因此 PPO 可以有限复用近期轨迹，不能把任意陈旧数据变成精确 on-policy 数据，也不保证每次得分提高。

LLM RLHF 另有 \(\pi_{\rm ref}\) 用于行为正则。old 是采样快照，reference 是约束参照；它们不是同一个职责。

## 10. GRPO：主要换的是优势估计

对同题多个候选获得 \(R_1,\ldots,R_G\)，结果监督 GRPO 用

\[
\hat A_i=\frac{R_i-\bar R}{\operatorname{std}(R)+\varepsilon}
\]

作为相对信号，再进入 PPO 类概率比目标。它省去独立 Critic，仍需要多次尝试和奖励。原始方法来自 DeepSeekMath。[^6]

从第一性原理看，重要性顺序是：**先知道为何优势乘 log-prob 导数是学习方向；再问用什么方式估计优势；最后问怎样裁剪、正则和聚合。** 不是先记住一个 GRPO 大公式。

组均值包含当前样本时会与当前动作相关。只做中心化、忽略标准差缩放时，在独立同分布候选等条件下，使用含自身组均值的期望梯度会带有 \((G-1)/G\) 缩放；leave-one-out baseline 排除自身，可以避免这个特定影响。再加入随机标准差和长度归一化后，权重关系更复杂，不能笼统声称所有 GRPO 实现都是原始回报梯度的无偏估计。

当全组结果一样时，中心化结果优势为零；这部分没有比较信号。更好的任务课程、起始策略、探索与奖励可区分性，比单纯增加训练步数更关键。

## 11. DPO：同样改变概率，但系数来自偏好分类

DPO 常用偏好对 \((x,y_w,y_l)\)，其中 w 是 preferred，l 是 dispreferred。记

\[
m_\theta=\beta\left[
\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\rm ref}(y_w\mid x)}-
\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\rm ref}(y_l\mid x)}\right],
\quad L_{\rm DPO}=-\log\sigma(m_\theta).
\]

直接求导得

\[
-\nabla L_{\rm DPO}
=\beta\sigma(-m_\theta)
\left[\nabla\log\pi_\theta(y_w\mid x)-\nabla\log\pi_\theta(y_l\mid x)\right].
\]

这揭示了参数更新方向：增加相对参考模型的 preferred／dispreferred 对数似然差。模型越没有满足这个偏好排序，系数越大；已把排序分开较远，系数越小。共享参数下仍不保证 preferred 的绝对概率在所有更新中都上升。

它与 KL 正则奖励最大化的联系来自最优策略的指数形式和 Bradley–Terry 偏好模型；但上述梯度是偏好损失的梯度，不应未经条件说明就称为任意真实环境期望回报的无偏策略梯度。标准 DPO 不需要在每个优化步骤在线执行环境。[^7]

因此不能把 DPO 放进“REINFORCE → Actor–Critic → PPO”单线升级史。它是同一类行为优化问题的另一条路线。

## 12. 用一张表结束第一部分

| 方法 | 反馈怎样变成学习系数 | 可微项 | 主要要解决的问题 |
|---|---|---|---|
| REINFORCE | 采样轨迹的 return | log-prob | 获得期望回报梯度 |
| baseline／Actor–Critic | return 减 baseline，或 TD／GAE | log-prob；另训 value | 降低噪声、改善估计效率 |
| PPO | 优势 × 概率比，配合 clip | 当前策略概率 | 稳定地复用近期数据 |
| GRPO | 同题候选构造相对优势 | PPO 类概率比项 | 无独立 Critic 的比较信号 |
| DPO | 偏好差决定 logistic 系数 | 两个回答的 log-prob 差 | 直接学习偏好排序 |

DQN 可放短附录：它直接对 \((Q_\theta(s,a)-\operatorname{stopgrad}(y))^2\) 求导，先改 Q 估计，再通过动作选择改变行为。它不使用这里的 Actor log-prob 梯度，不能硬套同一计算图。

## 13. 现场解释是否讲清楚的检验

听众应能解释：奖励不可微为何仍能训练；为什么用 log-prob；正负优势如何改变交叉熵方向；终局奖励为何能影响早期动作却不构成精确因果归因；Critic 改了估计的哪一部分；PPO 在 \(\rho=1\) 时为何退回熟悉方向；DPO 为何不能直接等同在线 RL。

建议把这些问题作为前半场的主线，把算法名字留作答案的标签。
