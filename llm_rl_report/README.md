开场跟着研究者遇到的问题走。先展示一个模型会续写却没完成指令的真实例子，再讲示范为什么有用、为什么还想用模型实际生成的回答继续训练。算法名等听众认识了奖励和策略之后再展开。

开场后的讲述顺序以基础文字稿为准。先把强化学习术语集中讲明白，再用三个例子练习对应。后续沿着策略梯度、基线、Actor–Critic、PPO 和 GRPO 展开。
