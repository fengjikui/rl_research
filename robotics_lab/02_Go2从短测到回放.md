# 02 让 Go2 从随机策略开始学走路

先完成 [01 配置 AutoDL](01_AutoDL从开机到IsaacLab.md)。本篇要让同一只仿真机器狗在平地上跟踪前进、侧移和转弯的速度指令，随后加载保存的策略回放。训练本身由 Isaac Lab 的 Go2 任务与 RSL-RL 的 PPO 入口完成。[Go2 任务注册代码](https://github.com/isaac-sim/IsaacLab/blob/37ddf626871758333d6ed89cf64ad702aef127d0/source/isaaclab_tasks/isaaclab_tasks/manager_based/locomotion/velocity/config/go2/__init__.py)

## 1. 激活环境并理解任务

在 AutoDL 终端设置运行环境。

```bash
set -o pipefail
export GO2_ROOT=/root/autodl-tmp/go2-ppo
export PATH="$GO2_ROOT/venv/bin:$PATH"
export XDG_CACHE_HOME="$GO2_ROOT/cache" TMPDIR="$GO2_ROOT/tmp"
export XDG_RUNTIME_DIR="$GO2_ROOT/runtime"
export VK_ICD_FILENAMES="$GO2_ROOT/nvidia-egl.json"
export OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4
KIT_THREADS=--/plugins/carb.tasking.plugin/threadCount=8
cd "$GO2_ROOT/IsaacLab"
python -V
nvidia-smi
df -h / "$GO2_ROOT"
```

首次启动按交互提示处理 Isaac Sim 许可。已同意时，可以设置 `OMNI_KIT_ACCEPT_EULA=YES` 供无交互的 SSH 命令使用。[Isaac Sim 首次运行说明](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/installation/install_python.html#running-isaac-sim)

```bash
python scripts/environments/list_envs.py --keyword Go2
```

训练选 `Isaac-Velocity-Flat-Unitree-Go2-v0`。本次策略网络收到 48 维输入，其中 12 维来自身体线速度、角速度、重力投影和速度指令，另外三个 12 维块分别是关节位置、关节速度和上一次动作。策略输出 12 维关节目标位置偏移。物理仿真每 5 毫秒推进一次，策略每隔 4 个物理步给一次新动作，也就是每秒 50 次。速度跟踪、动作平滑、姿态等项共同塑造步态，碰到终止条件时环境重置。[观察、动作与奖励源码导读](Go2_PPO逐步讲解.md)

## 2. 跑 10 轮短测

```bash
python -u scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Velocity-Flat-Unitree-Go2-v0 \
  --headless --kit_args="$KIT_THREADS" --num_envs 64 --max_iterations 10 --seed 42 \
  --run_name manual_smoke 2>&1 | tee "$GO2_ROOT/manual-smoke.log"
```

`--headless` 关闭可见窗口。`--kit_args` 在这台有 16 核配额的实例上把 Kit 任务线程设为 8。首次初始化需要加载 Go2 的 USD 资产和扩展缓存。用以下几项检查短测结果。

- 环境任务成功启动，能看到策略和价值网络。
- 10 次迭代有采样吞吐和有限的损失值。速度跟踪和平均奖励只是早期信号。
- 在 `logs/rsl_rl/unitree_go2_flat/<时间>_manual_smoke/` 下找到 `model_9.pt`、`params/env.yaml` 和 `params/agent.yaml`。
- 运行中用另一终端查看 `nvidia-smi` 和 cgroup 的内存、CPU 压力。若显存不足或温度持续升高，先降低并行规模。

每轮每个环境采 **24** 步，所以短测共采 **15,360 条转移**。收完一批转移，RSL-RL 计算回报和优势。优化阶段走 5 个 epoch，每个 epoch 分成 4 个小批次，每轮 PPO 共做 20 次优化器更新。下一轮再用新策略采样。[Go2 PPO 配置源码](https://github.com/isaac-sim/IsaacLab/blob/37ddf626871758333d6ed89cf64ad702aef127d0/source/isaaclab_tasks/isaaclab_tasks/manager_based/locomotion/velocity/config/go2/agents/rsl_rl_ppo_cfg.py)

2026-11-20 实测完成 10 轮和 15,360 条转移。训练入口报告用时 12.57 秒，另有仿真环境启动和资产加载时间。

## 3. 先试一小段录像

把下面的 `CHECKPOINT` 换成短测真实生成的路径。若第一次开相机遇到 Vulkan、RTX 或 EGL 报错，先确认第一篇的两个图形变量已导出，再查模拟器日志。

```bash
CHECKPOINT=/填写短测的绝对路径/model_9.pt
python -u scripts/reinforcement_learning/rsl_rl/play.py \
  --task Isaac-Velocity-Flat-Unitree-Go2-Play-v0 \
  --headless --kit_args="$KIT_THREADS" --num_envs 1 --seed 43 --checkpoint "$CHECKPOINT" \
  --video --video_length 150
find "$(dirname "$CHECKPOINT")/videos/play" -name '*.mp4'
```

150 步约为 3 秒仿真时间。视频能正常解码和看到机器人，才算通过这一步。检查点是模型参数，`play.py` 会把参数装回策略网络，让策略实际控制仿真机器人。

首次打开渲染可能花几分钟编译着色器。主日志长时间没有新行时，查看启动时打印的 Kit 日志路径。本次详细日志出现 `Waiting for RtPso async group async compilation`，说明当时仍在等待 RTX 编译。

本次通过录像验收，文件为 H.264、960×540、150 帧，抽帧确认能看到 Go2。实验版回放启用了跟随相机，便于在较长的回放里观察步态。

## 4. 从零正式训练

短测和录像通过后，可以用 **1024 个环境、300 轮**作为单张 4090 的起点。依据短测的吞吐、显存和热状态调整环境数。省略 `--resume` 和 `--checkpoint` 会按配置从随机初始化开始。

```bash
python -u scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Velocity-Flat-Unitree-Go2-v0 \
  --headless --kit_args="$KIT_THREADS" --num_envs 1024 --max_iterations 300 --seed 42 \
  --run_name manual_train 2>&1 | tee "$GO2_ROOT/manual-train.log"
```

按这组参数，一轮是 `1024 × 24 = 24,576` 条转移，300 轮约 **737 万**条。日志主要看采样与学习耗时、平均回报和回合长度、线速度跟踪奖励、终止原因、价值损失和策略损失。每 50 轮的检查点以及最后一个检查点可用来回放训练中途和结尾的策略。这里的 `model_0.pt` 已经可能经历第一次更新。

2026-11-20 的正式训练完整记录了 300 轮和 **7,372,800 条转移**。训练入口报告用时 **286.12 秒**。第一轮和最后一轮日志中的平均回报分别为 -0.49 和 12.58，平均回合长度分别为 11.2 和 1000 步。下面的回放会单独检查速度跟踪。

若使用今晚服务器准备的 `train-go2.sh`，它会额外保存 `initial/model_initial.pt`，其中是**同一次正式训练第一次更新前**的策略参数。脚本使用相同的官方网络和更新逻辑，新增的操作只是把初始参数写盘，便于做前后对照。

## 5. 回放并解释学到了什么

先列出本次运行生成的检查点。

```bash
find logs/rsl_rl/unitree_go2_flat -name 'model_*.pt' | sort -V
```

用上面的 `play.py` 分别加载选中的检查点。正式回放可换成 `--video_length 1000`，对应约 20 秒仿真时间。官方播放任务适合演示，它关闭了训练时的部分随机扰动。今晚的服务器另备 `evaluate-go2.sh`，用同一平地 Play 配置、同一评估种子、同一段长度和固定 **前进 0.75 m/s、侧移 0、转向 0** 的命令，分别评估初始、50 轮附近、最终策略。每段视频附带一份 JSON 指标记录。

| 指标 | 读法 |
| --- | --- |
| 平均前进速度 | 观察是否接近目标 0.75 m/s |
| 平面速度平均误差 | 同时反映走得太慢和向侧面漂移 |
| 身体触地终止次数 | 在固定 20 秒内对比跌倒行为，可同时核查录像 |
| 已完成回合数 | 帮助解释提前终止和尚未结束的回合 |

这个对照描述固定条件下的一个回放。评估地形变化、不同速度指令或抗扰能力，需要增加评估条件和随机种子。

### 默认指令实验的实测结果

每个检查点都接到相同的 0.75 m/s 前进指令，评估 1000 步。速度统计剔除了终止时已被环境内部重置的观测。

| 默认任务检查点 | 平均前进速度（m/s） | 平面速度平均误差（m/s） | 身体触地终止次数 |
| --- | ---: | ---: | ---: |
| 初始策略 | -0.005 | 0.755 | 0 |
| `model_50.pt` | -0.0004 | 0.750 | 0 |
| `model_299.pt` | -0.005 | 0.756 | 0 |

三段回放都没有因身体触地而终止，平均前进速度均接近零。默认任务这轮的实际收获是完成了 PPO 训练和回放，并定位到速度跟踪没有达标。训练日志的平均回报混合了转向跟踪、身体姿态、动作成本和线速度跟踪，单看总回报容易漏掉前进这一项。

## 6. 把前进单独做成一个实验

默认任务同时采样前进、后退、侧移和朝向变化。在新的运行目录里从随机策略训练，把指令改成前进速度 0.55 到 0.95 m/s，侧移和转向设为 0。保留同一套 PPO 配置和奖励，增加采样规模到 2048 个环境和 400 轮。这是在更窄的任务上训练，也使用了更多样本。

```bash
python -u scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Velocity-Flat-Unitree-Go2-v0 \
  --headless --kit_args="$KIT_THREADS" --num_envs 2048 --max_iterations 400 --seed 42 \
  --run_name forward_only agent.experiment_name=unitree_go2_forward \
  env.commands.base_velocity.heading_command=false \
  env.commands.base_velocity.rel_standing_envs=0.0 \
  'env.commands.base_velocity.ranges.lin_vel_x=[0.55,0.95]' \
  'env.commands.base_velocity.ranges.lin_vel_y=[0.0,0.0]' \
  'env.commands.base_velocity.ranges.ang_vel_z=[0.0,0.0]'
```

在运行目录的 `params/env.yaml` 检查指令确实生效。训练时重点看 `Episode_Reward/track_lin_vel_xy_exp` 与 `Metrics/base_velocity/error_vel_xy`。后者按指令重采样步数归一化并累加，适合在同一训练配置里看趋势。回放另算每步的平均误差，继续使用 0.75 m/s、种子 43 和相同的 20 秒时长，便于比较不同策略在这条指令上的表现。

2026-11-20 的前进专项完成了 400 轮和 **19,660,800 条转移**，训练入口报告耗时 **394.31 秒**。最终策略在 0.75 m/s 的指令下，平均前进 **0.744 m/s**，平面平均误差 **0.033 m/s**，20 秒内身体触地终止 **0 次**。评估脚本同时记录了实际送进环境的平均指令，核对它确实为 0.75 m/s，侧移和转向分量为 0。

| 前进专项检查点 | 平均前进速度（m/s） | 平面速度平均误差（m/s） | 身体触地终止次数 |
| --- | ---: | ---: | ---: |
| 初始策略 | -0.003 | 0.753 | 0 |
| `model_150.pt` | 0.722 | 0.065 | 0 |
| `model_399.pt` | 0.744 | 0.033 | 0 |

本次 AutoDL 实例的训练、回放和安装文件共占用数据盘约 36 GB，结束时还有约 15 GB 可用空间。

## 7. 用自己的话复盘

看完三段，可以试着回答下面三个问题。

1. 一次仿真步里，速度指令从哪里进入策略，关节目标又怎么变成运动？
2. 把环境从 64 个加到 1024 个，为什么一轮要收更多转移？模型的输出维数有没有变？
3. 如果视频里机器狗站得很稳，但速度误差仍然很大，应该回头看哪些奖励项和指令？

保留训练配置、核对过的检查点、日志和回放。它们足够定位每段视频对应的策略，也方便用同样输入复跑。
