# 00｜相同的反向传播，为什么得到不同能力？

## 先校准这张总图

你提出的“神经网络结构＋数据＋损失”抓住了核心，但实践里还要把数据产生方式、训练算法与推理系统单列。一个有用的表达是：

**可用信息与表示 → 参数化模型 → 输出分布 → 数据／交互 → 学习目标 → 梯度估计与优化 → 评价与使用方式。**

这些层不能混成一个名字。Transformer 是一种结构；语言建模是任务与概率建模方式；交叉熵是损失；Adam 是优化器；PPO 是包含采样和代理目标的策略优化方法；工具 Agent 是模型与环境组成的系统。

## 同一个训练骨架

```python
data = collect_or_load_data()
prediction = model(data.inputs)
loss = objective(prediction, data)
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

它说明如何使用梯度，但没有说明正确训练的全部。SFT 中 `data` 可以是固定答案；DQN 中包含自己采到的转移，目标依赖另一个网络；PPO 中还要保存旧动作概率和优势；DPO 中要有偏好对与参考概率。循环相同，学习问题不同。

强化学习也不必有神经网络：下一课的 Q 表直接更新数字，不需要反向传播。现代神经网络训练大多用梯度法，但不能扩展成“所有模型、所有学习都这样”。

## 固定结构，换目标

给相同状态 s，一个 MLP 可以输出三个数：

| 用法 | 三个数代表什么 | 损失监督什么 |
|---|---|---|
| 动作分类 | 三个动作的 logits | 与专家动作的交叉熵 |
| DQN | 三个动作的预期回报 Q | 与 Bellman 目标的回归误差 |
| 策略梯度 | 三个动作的 logits | 实际动作 log 概率乘以优势 |

结构并不自动决定输出语义；数据、目标与使用方法一起决定。DQN 输出不能直接解释成归一化概率。策略 logits 的大小也不能直接解释成未来得分。

第 06 课将保持一个 Transformer 的结构和初始权重一致，分别用 SFT、DPO 和 GRPO。不要预设 RL 一定胜过 SFT：当正确答案标签便宜且充足时，SFT 往往是应当认真比较的基线。

## 固定目标，换结构

同样最大化接球得分，MLP 可以展平画面，CNN 可以保留二维邻域；同样预测最后应选左还是右，有记忆的模型可以利用先前线索。区别在于结构规定了信息怎样流动、参数怎样共享、哪些函数更容易表达和学到。

“都能反向传播”类似于“都能用数值方法求解”：它不意味着求解的是同一个问题，也不意味着成本、信息和优化难度相同。

## 统一记号

| 量 | 本系列中的含义 |
|---|---|
| B | 一批样本或并行环境数 |
| T | 时间步数或 token 长度，具体看每课 |
| s／h | 当前可用观测／历史 |
| a | 游戏动作或生成 token |
| πθ | 参数为 θ 的策略分布 |
| R／G | 单次结果或之后的累计回报 |
| A | 相对于基准的动作评价，用作 Actor 学习系数 |
| V／Q | 状态／状态动作的未来回报估计 |
