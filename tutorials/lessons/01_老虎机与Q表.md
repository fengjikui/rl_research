# 01｜第一次亲手更新：老虎机与 Q 表

## 实验 A：三个按钮，哪个更值得按？

代码：[00_bandit.py](../code/00_bandit.py)。三个动作得到 1 分的概率分别为 0.1、0.4、0.9；失败得 0。训练器不知道这些概率，只看到自己选的动作与结果。真实概率仅用于绘制期望得分。

```bash
python tutorials/code/00_bandit.py --out tutorials/runs/my_bandit
```

模型只有三个可训练 logits：`torch.nn.Parameter(torch.zeros(3))`。它没有隐层，因为这道题没有输入状态，不需要学复杂表示。强行使用一个 Transformer 不会增加必要信息。

| 对象 | 形状 | 意义 |
|---|---|---|
| logits | `[3]` | 三个动作的未归一化偏好 |
| actions | `[64]` | 本批实际选择 |
| rewards、advantage、log_prob | `[64]` | 每次选择的学习量 |
| loss | 标量 | 批平均代理损失 |

核心代码：

```python
dist = Categorical(logits=logits)
actions = dist.sample((64,))
rewards = torch.bernoulli(reward_means[actions])
loss = -((rewards - 0.5).detach() * dist.log_prob(actions)).mean()
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

采样动作不求导，奖励也不求导。梯度通过所选动作的 log 概率流到 logits。0.5 是动作无关的固定 baseline；它影响方差，不改变期望策略梯度。没有下一状态，所以这是一种最短的强化学习问题。

查看 `results.json` 中三个动作的最终概率和 `curve.png`。预期得分提高不要求某一次采样必定成功：选择最优按钮也有 10% 失败概率。

**修改实验：** 把 batch 从 64 改为 1，比较噪声；把学习率提高 10 倍，观察稳定性；把三个真实概率都设为 0.5，解释为什么没有唯一最优动作。每次改动另设输出目录，至少比较三个 seed。

## 实验 B：奖励在走廊尽头，怎么传回开头？

代码：[01_q_table.py](../code/01_q_table.py)。走廊位置 0–5，从 0 出发，向左或向右。到 5 得 1 分并结束，其他步得 −0.02。

```bash
python tutorials/code/01_q_table.py --out tutorials/runs/my_q_table
```

“模型”是形状 `[6,2]` 的表格。每格存一个位置下某动作的估计价值。更新为：

\[
y=r+\gamma(1-d)\max_{a'}Q(s',a'),\qquad
Q(s,a)\leftarrow Q(s,a)+\alpha[y-Q(s,a)].
\]

临近终点的 Q 先通过实际奖励升高；更早位置随后通过下一位置的估值学习。不是把终点奖励在神经网络里连续反传穿过整个走廊，而是反复更新 Bellman 关系。

训练以 25% 概率随机探索。评估用贪心动作，输出路径。`greedy_path` 应朝终点移动，但具体训练过程受 seed 与参数影响。

代码中的 40 步只是采样器的一次收集上限，没有当作游戏吸收终点，因此最后一步的目标仍允许 bootstrap。真正到达 5 才清零后续价值。这个区别会在 PPO 与真实 Agent 中反复出现。

## 本课应该留下的认识

老虎机直接优化动作概率；Q-learning 学习动作价值再用它选动作。两者都可以是强化学习，却不是同一个学习目标。下一课只把无法扩展到复杂状态的 Q 表换成神经网络，保留价值学习的思想。

原理参考：[Sutton 与 Barto 教材](http://incompleteideas.net/book/the-book-2nd.html)，Bandits 与 Temporal-Difference Learning 章节。
